# Murang'a County Supabase Auth Email Templates

These HTML templates are styled to match the official **Murang'a County Public Service Request System** design:
- **Primary Color:** Murang'a Green (`#1E6B34`)
- **Accent Color:** Warm Gold (`#D4A017`)
- **Footer Theme:** Admin Dark (`#1A1A1A`)
- **Branding:** Official County Seal / Logo with bulletproof responsive email layout compatible with Gmail, Outlook, Apple Mail, and mobile clients.

---

## How to Apply in Supabase Dashboard

1. Log into your [Supabase Dashboard](https://supabase.com/dashboard).
2. Select your project.
3. In the left navigation sidebar, navigate to:
   **Authentication** &rarr; **Email Templates**.

---

### 1. Confirm Signup Template
1. Under **Email Templates**, select **Confirm signup**.
2. **Subject:**
   ```text
   Confirm your Murang'a County Public Service Account
   ```
3. **Message Body (HTML):**
   - Copy the entire contents of [`supabase/templates/confirm-signup.html`](./confirm-signup.html) and paste it into the code editor.
4. Click **Save Changes**.

---

### 2. Reset Password Template
1. Under **Email Templates**, select **Reset password**.
2. **Subject:**
   ```text
   Reset your Murang'a County Portal Password
   ```
3. **Message Body (HTML):**
   - Copy the entire contents of [`supabase/templates/reset-password.html`](./reset-password.html) and paste it into the code editor.
4. Click **Save Changes**.

---

## Supabase Template Variables Used

- `{{ .SiteURL }}`: Dynamically resolves to your configured Site URL (e.g. `http://localhost:3000` or production domain) to render the county logo.
- `{{ .ConfirmationURL }}`: The secure, one-time verification link generated by Supabase Auth with token validation.

> **Tip on Logo Visibility in Local Development:**
> In local development (`localhost`), external email providers (like Gmail) cannot fetch images from `http://localhost:3000/images/muranga-logo.webp`. 
> When deploying to production (e.g., Vercel), set your **Site URL** in **Authentication &rarr; URL Configuration** to your public production URL (e.g. `https://your-domain.vercel.app`), and email clients will automatically load the full-color county seal.
